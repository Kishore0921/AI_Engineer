# Day 8 — Advanced Prompt Engineering

## Learning objective
Recognize reusable prompt patterns and improve prompts through structured testing.

## Topics and subtopics
1. Prompt engineering roadmap.
2. Prompt engineering terminology.
3. Prompt patterns.
4. Advanced prompting techniques.
5. Reusable prompt structures.
6. Prompt testing.

## Important concepts
- A prompt pattern is a reusable structure for a recurring task, not a guarantee of correct output.
- Make task, context, constraints, and expected format explicit.
- Test prompts against representative examples, including ambiguous or difficult cases.
- Keep versions and compare outputs against criteria before reusing a prompt.

## Key terminology
Prompt pattern, reusable prompt, role/instruction, context, constraint, example, test case, evaluation criterion.

## Learning outcomes
- Identify useful prompt-engineering terminology and patterns.
- Create prompt templates that can be reused with variable inputs.
- Test examples and record why a prompt is or is not effective.
