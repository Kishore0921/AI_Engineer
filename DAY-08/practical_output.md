# Day 8 Practical — Create a reusable prompt library with tested examples

## Practical objective
Build an organized library of reusable prompts and evidence of how they perform on example inputs.

## Exact practical output
**Create a reusable prompt library with tested examples.**

## Tasks
1. Choose several recurring, low-risk tasks and define the desired output for each.
2. Create a reusable prompt structure for each task, clearly marking where user-provided input belongs.
3. Add a small set of representative test inputs per prompt, including at least one edge or ambiguous case.
4. Run each example under consistent conditions and record the outputs and evaluation notes.
5. Revise prompts based on observed failures and retain the tested examples.

## Expected result
A prompt library with named templates, input slots, test examples, and concise evidence-based notes.

## Completion checklist
- [x] Reusable prompt templates are named and organized.
- [x] Input slots and output expectations are clear.
- [x] Examples include a challenging case.
- [x] Outputs and revisions are documented.
