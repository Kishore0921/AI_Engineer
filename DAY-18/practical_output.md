# Day 18 Practical — Compare vector databases and select one for your project

## Practical objective
Assess the listed vector database choices against the needs of a small retrieval project.

## Exact practical output
**Compare vector databases and select one for your project.**

## Tasks
1. Compare Chroma, Pinecone, Weaviate, FAISS, LanceDB, Qdrant, Supabase, and MongoDB Atlas using current documentation.
2. For each, record deployment style, persistence, metadata filtering, setup effort, relevant integrations, and pricing/operational considerations where applicable.
3. Distinguish local libraries from hosted/managed services rather than assuming equivalent operation.
4. Define the likely requirements of your document-search project.
5. Choose one candidate and explain why it fits; note what needs re-evaluation at larger scale.

## Expected result
A concise comparison matrix and a justified vector database selection for the project.

## Completion checklist
- [ ] All eight named options are considered.
- [ ] Comparison criteria and sources/date are recorded.
- [ ] Project requirements are explicit.
- [ ] One choice and its trade-offs are explained.
