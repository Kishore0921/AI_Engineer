# Day 6 Practical — Experiment with different prompts and parameters, and document the output changes

## Practical objective
Use controlled experiments to observe how prompt wording and supported parameters affect model outputs.

## Exact practical output
**Experiment with different prompts and parameters, and document the output changes.**

## Tasks
1. Select a simple task and record the model, date, and baseline prompt.
2. Submit the baseline prompt more than once to observe natural response variation.
3. Change one prompt element (such as context or output format) and record the result.
4. Change one supported parameter at a time; record its value and output. Do not assume parameter names or ranges are identical across models.
5. Add a short fine-tuning concept note: what it changes and why it differs from prompt experimentation.

## Expected result
An experiment log that isolates prompt and parameter changes and describes observed—not assumed—effects.

## Completion checklist
- [ ] Baseline and model details are recorded.
- [ ] Prompt and parameter changes are isolated.
- [ ] Multiple outputs are compared.
- [ ] Fine-tuning concept is distinguished from prompting.
