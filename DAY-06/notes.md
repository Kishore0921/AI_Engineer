# Day 6 — OpenAI Playground and Fine-Tuning

## Learning objective
Experiment systematically with prompts and model parameters in the Playground and understand fine-tuning at a conceptual level.

## Topics and subtopics
1. OpenAI Playground.
2. Fine-tuning concepts.
3. Model capabilities.
4. Model limitations.
5. Experimenting with prompts and parameters.
6. Understanding output changes.

## Important concepts
- A Playground provides an interactive way to test prompts and supported model settings.
- Change one variable at a time to understand its effect; repeated generations can vary.
- Fine-tuning adapts a model using examples for a narrower behavior; it is not a substitute for current knowledge or retrieval.
- Model limitations persist even when a prompt or parameter is adjusted.

## Key terminology
Playground, fine-tuning, training example, model parameter, temperature, output variation, capability, limitation.

## Learning outcomes
- Run controlled prompt/parameter experiments.
- Explain observed output changes without overgeneralizing from one sample.
- Describe what fine-tuning is and when its concept differs from prompt changes.
