# Day 7 — Week 1 Revision and Integration

## Learning objective
Consolidate the first week's AI/LLM and API concepts by integrating them into a basic chatbot.

## Topics and subtopics
1. Revise AI and LLM fundamentals.
2. Revise API concepts.
3. Practice API integration.
4. Combine concepts learned during the week.
5. Build a basic AI chatbot.

## Important concepts
- A chatbot sends conversation context to a model and presents the response to a user.
- Conversation history consumes context; decide what messages to include.
- A useful integration handles empty input, errors, and unavailable credentials without pretending a request succeeded.
- The model can produce incorrect or unsafe content; keep the interface simple and review responses.

## Key terminology
Chatbot, conversation history, message, API integration, context, user input, response handling.

## Learning outcomes
- Recall the week's AI, LLM, prompt, and API foundations.
- Build and test a basic chatbot using an API.
- Identify the chatbot's limits and explain its integration flow.
