# Day 2 — Understanding Large Language Models

## Learning objective
Build a conceptual model of LLMs and distinguish model training from using a trained model to answer requests.

## Topics and subtopics
1. What are Large Language Models (LLMs)?
2. How LLMs work.
3. Inference.
4. Training.
5. Pre-trained models.
6. Benefits and limitations of LLMs.
7. Considerations when using LLMs.

## Important concepts
- An LLM learns statistical patterns from training data and generates text from a sequence of tokens.
- Training adjusts model parameters; inference uses an existing model to produce an output.
- A pre-trained model can be used as-is or adapted for a task, but its output is not guaranteed to be correct.
- Consider capability, context limits, privacy, cost, latency, bias, and output verification when choosing a model.

## Key terminology
Large language model (LLM), token, parameter, training, pre-training, inference, prompt, context length, hallucination.

## Learning outcomes
- Explain at a high level how an LLM generates a response.
- Distinguish training and inference.
- Run a pre-trained model and identify useful capabilities and limitations.
