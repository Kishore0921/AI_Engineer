# Day 2 Practical — Run a pre-trained model and record its inputs, outputs and limitations

## Practical objective
Observe an existing model's behavior with controlled inputs and report what it can and cannot reliably do.

## Exact practical output
**Run a pre-trained model and record its inputs, outputs and limitations.**

## Tasks
1. Choose an available pre-trained model and note its name, provider/runtime, and task.
2. Prepare a few small, non-sensitive prompts that test distinct behaviors (for example, summarization and factual explanation).
3. Run each prompt without changing the model between trials; save the exact input and output.
4. Note one response that appears useful and one limitation, uncertainty, or possible error.
5. Record whether the model was accessed locally or through a hosted service; do not include credentials.

## Expected result
A short reproducible experiment log containing the model, inputs, outputs, and evidence-based limitations.

## Completion checklist
- [ ] Pre-trained model and access method are identified.
- [ ] Inputs and outputs are recorded accurately.
- [ ] At least one capability and limitation are discussed.
- [ ] No sensitive input or secret is included.
