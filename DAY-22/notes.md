# Day 22 — Introduction to AI Agents

## Learning objective
Understand the components of an AI agent and build toward a controlled workflow in which model decisions lead to bounded actions.

## Topics and subtopics
1. What are AI agents?
2. AI agent use cases.
3. Agent prompting.
4. ReAct framework.
5. Agent reasoning and actions.
6. Controlled agent workflows.

## Important concepts
- An agent uses a model to select or coordinate actions toward a task; autonomy should be limited to what the application needs.
- ReAct describes an iterative reasoning-and-action pattern; model-generated reasoning should not be treated as proof or exposed as reliable truth.
- Define allowed actions, input validation, execution limits, and stopping conditions.
- Keep actions observable and require confirmation for consequential external effects.

## Key terminology
AI agent, agent prompt, ReAct, action, observation, tool, control flow, stopping condition.

## Learning outcomes
- Describe how agent prompting, reasoning/actions, and observations fit together.
- Identify appropriate agent use cases and boundaries.
- Build a basic controlled agent workflow with limited actions.
