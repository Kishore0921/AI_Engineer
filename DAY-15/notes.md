# Day 15 — Understanding Embeddings

## Learning objective
Understand vector representations of text and generate embeddings while considering dimensions, API usage, and cost.

## Topics and subtopics
1. What are embeddings?
2. How embeddings work.
3. OpenAI embedding models.
4. Embedding API.
5. Embedding pricing.
6. Vector dimensions.
7. Generating embeddings.

## Important concepts
- An embedding maps content to a numeric vector intended to capture useful patterns or semantic relationships.
- Similarity measures can compare vectors, but the result depends on the model, normalization, and metric.
- Vectors have a fixed number of dimensions for a given model; do not assume dimensions are interchangeable across models.
- Embedding APIs and prices vary; estimate workload and check current provider documentation.

## Key terminology
Embedding, vector, dimension, embedding model, embedding API, similarity, cosine similarity, vector normalization.

## Learning outcomes
- Explain what an embedding represents and what its numeric dimensions mean at a high level.
- Generate an embedding for text using an available model/API.
- Inspect vector shape and document the model and cost considerations.
