# Day 11 Practical — Create a model comparison sheet covering quality, speed, cost, privacy and hardware

## Practical objective
Create a decision aid for choosing between accessible open-source and closed-source models.

## Exact practical output
**Create a model comparison sheet covering quality, speed, cost, privacy and hardware.**

## Tasks
1. Select representative models from both open-source and closed-source options; record model versions and licenses where available.
2. Choose a small common task set and a consistent quality rubric.
3. Record measured or sourced quality, speed, and cost evidence; label estimates and unknowns rather than guessing.
4. Compare data handling/privacy terms and local hardware needs.
5. Write a short recommendation for one use case and state the trade-offs behind it.

## Expected result
A side-by-side comparison sheet with evidence, explicit unknowns, and a use-case-specific recommendation.

## Completion checklist
- [ ] Both model approaches are represented.
- [ ] Quality, speed, cost, privacy, and hardware are addressed.
- [ ] Sources, dates, licenses, and estimates are identified.
- [ ] Recommendation states its use case and trade-offs.
