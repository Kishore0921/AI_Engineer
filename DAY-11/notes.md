# Day 11 — Open-Source vs Closed-Source Models

## Learning objective
Compare model access and licensing approaches and select a model based on quality, speed, cost, privacy, and hardware constraints.

## Topics and subtopics
1. Open-source models.
2. Closed-source models.
3. Popular open-source models.
4. Model selection.
5. Quality considerations.
6. Speed and cost.
7. Privacy and hardware requirements.

## Important concepts
- “Open source” can mean different levels of access to weights, code, data, and usage rights; check each model's license.
- Hosted closed-source models can simplify access but involve provider terms, cost, and data-processing considerations.
- Local models increase control but require suitable hardware and operational work.
- Compare models on the same task and measure quality, latency, and cost for the intended workload.

## Key terminology
Open-source model, closed-source model, model weights, license, hosted inference, local inference, latency, hardware requirement.

## Learning outcomes
- Describe practical differences between hosted closed-source and open models.
- Compare model suitability using consistent criteria.
- State privacy, license, cost, and hardware trade-offs in a model choice.
