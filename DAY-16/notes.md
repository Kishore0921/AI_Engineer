# Day 16 — Sentence Transformers and Open-Source Embeddings

## Learning objective
Generate sentence embeddings with open-source tooling and compare model behavior on a small, consistent set.

## Topics and subtopics
1. Sentence Transformers.
2. Hugging Face embeddings.
3. Open-source embedding models.
4. Generating sentence embeddings.
5. Comparing embedding models.

## Important concepts
- Sentence Transformers provides models and utilities for sentence-level embeddings.
- Hugging Face model cards document tasks, model identifiers, and usage conditions.
- Embedding model choice affects vector dimensions and semantic similarity; compare using representative examples.
- Different embedding spaces should not be mixed for similarity search unless specifically supported.

## Key terminology
Sentence Transformers, sentence embedding, Hugging Face, open-source embedding model, vector space, similarity.

## Learning outcomes
- Select a documented open-source embedding model.
- Generate sentence embeddings and inspect their shape.
- Compare multiple models on the same text examples and record differences.
