# Day 19 — Vector Search and Indexing

## Learning objective
Store document embeddings in a searchable index and retrieve relevant content using vector similarity.

## Topics and subtopics
1. Vector search.
2. Indexing embeddings.
3. Similarity search.
4. Retrieving relevant information.
5. Searching stored document embeddings.

## Important concepts
- Indexing organizes vectors to support efficient retrieval.
- Search results are ranked candidates; relevance depends on embedding model, data, metric, and query.
- Keep each vector connected to its source document and useful metadata.
- Test retrieval with known queries and verify returned passages before using them downstream.

## Key terminology
Vector search, index, similarity search, top-k, metadata, document embedding, retrieval, ranking.

## Learning outcomes
- Index document embeddings using a suitable local or database option.
- Search stored vectors and return source-associated results.
- Evaluate whether retrieved information is relevant to test queries.
