# Day 17 — Semantic Search and Embedding Applications

## Learning objective
Use vector similarity to retrieve conceptually related text and recognize other embedding application areas.

## Topics and subtopics
1. Semantic search.
2. Data classification.
3. Recommendation systems.
4. Anomaly detection.
5. Embedding use cases.
6. Similarity between text representations.

## Important concepts
- Semantic search ranks text by meaning-related vector similarity rather than exact keyword overlap alone.
- Embeddings can support classification, recommendations, and anomaly detection, but each use case needs suitable data and evaluation.
- Similarity is a ranking signal, not proof that two statements are equivalent or factually related.
- A useful search system tests both relevant and irrelevant examples and inspects ranking quality.

## Key terminology
Semantic search, similarity score, nearest neighbor, classification, recommendation, anomaly detection, embedding use case.

## Learning outcomes
- Explain semantic search and how embeddings support it.
- Build search over a small text collection.
- Identify classification, recommendation, and anomaly-detection applications and their evaluation needs.
