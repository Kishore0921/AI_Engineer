# Day 3 Practical — Compare five AI models using the same small set of tasks

## Practical objective
Make a repeatable, evidence-based comparison across the five model providers.

## Exact practical output
**Compare five AI models using the same small set of tasks.**

## Tasks
1. Select one accessible model from each of OpenAI, Anthropic Claude, Google Gemini, Mistral, and Cohere; note model names and test date. If access to a provider is unavailable, clearly record that constraint instead of inventing a result.
2. Write a small set of identical, non-sensitive tasks and prompts.
3. Submit the same prompts to each available model, keeping settings comparable where possible.
4. Record outputs and compare them against explicit criteria such as relevance, correctness, clarity, latency, and cost information available to you.
5. Summarize trade-offs without claiming an unsupported universal winner.

## Expected result
A comparison table with model identity, common prompts, observations, and access limitations.

## Completion checklist
- [x] Five model/provider slots are considered and identified.
- [x] The same task set is used for each available model.
- [x] Outputs and comparison criteria are recorded.
- [x] Access gaps and date are transparent.
