# Day 3 — Understanding the AI Model Ecosystem

## Learning objective
Recognize major model providers and compare their capabilities using a consistent task set rather than brand assumptions.

## Topics and subtopics
1. OpenAI.
2. Anthropic Claude.
3. Google Gemini.
4. Mistral.
5. Cohere.
6. Model capabilities and differences.

## Important concepts
- Providers offer different model families, interfaces, supported modalities, limits, and terms.
- Model capabilities and availability change; comparisons should record the date and specific model tested.
- A fair comparison holds prompts and evaluation criteria constant.
- Selection depends on task quality, latency, cost, context needs, privacy, and integration constraints.

## Key terminology
Model provider, model family, capability, modality, benchmark, evaluation criteria, latency, context window.

## Learning outcomes
- Identify the five providers in the syllabus.
- Compare five models on the same small task set and explain observed differences.
- Avoid treating a single response as a definitive model ranking.
