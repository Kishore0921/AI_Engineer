# Day 5 — Prompt Engineering Fundamentals

## Learning objective
Write clear prompts and understand how tokens, output limits, and pricing affect an API interaction.

## Topics and subtopics
1. What is a prompt?
2. Writing effective prompts.
3. Prompt structure.
4. Maximum tokens.
5. Token counting.
6. API pricing.
7. Managing tokens.

## Important concepts
- A prompt is the instruction and context provided to a model.
- Specific goals, relevant context, constraints, and an explicit output format make requests easier to evaluate.
- Tokenization is model-dependent; character or word counts are not exact token counts.
- Input and output limits and pricing vary by model and can change.
- Control prompt size and requested output, then verify both token usage and the current price source.

## Key terminology
Prompt, instruction, context, constraint, output format, token, tokenizer, maximum output tokens, input token, output token.

## Learning outcomes
- Structure a prompt for an explicit task and output.
- Compare responses while keeping other conditions stable.
- Estimate and record token usage and applicable pricing without assuming fixed rates.
