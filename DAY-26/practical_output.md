# Day 26 Practical — Build an image-based application and compare models

## Practical objective
Create an image-based application and evaluate its output across available multimodal models.

## Exact practical output
**Build an image-based application and compare models.**

## Tasks
1. Choose a bounded image task, such as describing a permitted sample image or answering a question about it.
2. Implement the task with one available option among OpenAI Vision API, DALL-E API (for generation-related tasks), or a suitable Hugging Face multimodal model.
3. Select a second accessible model for comparison; record model names and test date.
4. Use the same task prompt and comparable image/input conditions; compare against criteria appropriate to the task.
5. Record output differences, latency/cost information if available, limitations, and unavailable model access without fabricating results.

## Expected result
A working image-based prototype plus a fair comparison record for the models that could actually be tested.

## Completion checklist
- [ ] Image use and task are appropriate.
- [ ] Prototype runs or the access blocker is documented.
- [ ] Model identities and shared test conditions are recorded.
- [ ] Comparison criteria and observations are included.
