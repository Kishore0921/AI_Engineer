# Day 26 — Vision and Image Generation APIs

## Learning objective
Explore vision and image-generation APIs and compare multimodal models for a specific image-based application.

## Topics and subtopics
1. OpenAI Vision API.
2. DALL-E API.
3. Hugging Face multimodal models.
4. Image-based AI applications.
5. Comparing multimodal models.

## Important concepts
- Vision APIs accept visual inputs for tasks such as describing or answering questions about images.
- Image-generation APIs create images from prompts; output, controls, and usage terms vary by service.
- Hugging Face offers multimodal model options with different tasks, hardware needs, and licenses.
- Compare models using the same permitted image/task and criteria such as relevance, quality, latency, cost, and limitations.

## Key terminology
Vision API, DALL-E API, multimodal model, image-generation prompt, image-based application, model comparison.

## Learning outcomes
- Identify the listed vision and image-generation options.
- Build an image-based prototype using an available model/API.
- Compare model results on shared criteria and document access limits.
