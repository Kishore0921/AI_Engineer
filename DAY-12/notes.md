# Day 12 — Hugging Face Fundamentals

## Learning objective
Navigate the Hugging Face Hub to identify a suitable model and understand how to download and run it.

## Topics and subtopics
1. Hugging Face Hub.
2. Finding models.
3. Understanding model tasks.
4. Using open-source models.
5. Downloading models.
6. Running suitable models.

## Important concepts
- The Hub hosts model artifacts and metadata; check the model card, task, license, and intended use.
- A model's task and architecture determine how it can be loaded and used.
- Downloading weights can require significant storage and compatible hardware.
- Prefer a suitable, trusted model and follow its license and usage restrictions.

## Key terminology
Hugging Face Hub, model card, task, weights, Transformers, tokenizer, license, inference.

## Learning outcomes
- Find and assess a model using its task and documentation.
- Identify runtime, hardware, and license requirements before downloading.
- Download and run a suitable open-source model when the environment permits.
