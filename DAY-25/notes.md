# Day 25 — Introduction to Multimodal AI

## Learning objective
Understand how AI applications process more than one modality and explore image understanding and image generation.

## Topics and subtopics
1. What is multimodal AI?
2. Multimodal AI use cases.
3. Image understanding.
4. Image generation.
5. AI applications involving images.

## Important concepts
- Multimodal AI handles or combines different data types, such as text and images.
- Image understanding produces interpretations of image content; image generation creates images from instructions.
- Image input can be ambiguous, incomplete, or contain private information; verify interpretations and respect consent.
- Use cases should state what the system can infer and what remains uncertain.

## Key terminology
Multimodal AI, modality, image understanding, image generation, vision model, prompt, visual input.

## Learning outcomes
- Define multimodal AI and give examples of image use cases.
- Distinguish understanding an image from generating one.
- Build an image-understanding application and note its uncertainty and privacy considerations.
