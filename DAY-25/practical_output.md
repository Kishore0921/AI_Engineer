# Day 25 Practical — Build an image-understanding application

## Practical objective
Create a small application that accepts an image and a question and returns a model-generated description or answer.

## Exact practical output
**Build an image-understanding application.**

## Tasks
1. Select an available vision-capable model and review supported image formats, limits, and data terms.
2. Choose a non-sensitive image you are allowed to use and prepare a clear question about it.
3. Build a minimal interface or script that sends the image and prompt through the documented API/model workflow.
4. Display the result and explain that generated interpretations may be wrong; test one ambiguous visual question.
5. Record the model, image source/permission, prompt, output summary, and limitations.

## Expected result
A working image-understanding prototype with a documented, permitted test image and a reviewed output.

## Completion checklist
- [ ] Model and supported input requirements are checked.
- [ ] Image use is permitted and non-sensitive.
- [ ] Application passes image and prompt and displays a result.
- [ ] Ambiguity and output limitations are noted.
